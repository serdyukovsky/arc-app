# ARC — контекст проекта

Личный трекер привычек Константина (Барнаул, UTC+7). Тексты для пользователя — на русском.
С 24.10.2026 сюда перенесена механика routine-bot (`~/routine-bot`, выключен): ARC — единственный бот привычек.

## Что из чего

| Часть | Где | Что делает |
|---|---|---|
| Mini App (React + Vite) | `src/`, на сервере `/var/www/arc-app`, https://gidmate.ru/ | создание привычек, отметки, выбор дня, аналитика |
| PocketBase 0.25 | `/opt/arc-pocketbase` (systemd `arc-pocketbase`, 127.0.0.1:8091), хуки `pocketbase/pb_hooks`, миграции `pocketbase/pb_migrations` | **источник правды** |
| Сервис уведомлений (Node 20, tsx) | `notification-service/`, на сервере `/opt/arc-notifications` (systemd `arc-notifications`) | бот @mybestroutine_bot: блоки, кнопки, доводчик, фразы, команды, выгрузка в таблицу |

## Бот (notification-service)

- **Один пользователь:** `ALLOWED_TELEGRAM_ID` (сервис) и `ARC_ALLOWED_TELEGRAM_IDS` (вход в приложение, drop-in
  `/etc/systemd/system/arc-pocketbase.service.d/allowed-users.conf`). Остальные 3 пользователя в базе — исторические, им ничего не шлём.
- **Telegram — только через прокси** `TELEGRAM_PROXY=http://127.0.0.1:10809` (xray-клиент `xray-maxbot` на хосте; напрямую
  с сервера в РФ соединения виснут). PocketBase и Google — напрямую.
- **Сообщение-блок:** привычки с одним временем напоминания → одно сообщение, кнопка на привычку (`h:<habitId>:<date>`),
  правится на месте. Счётчики — без кнопки. Отметить можно сегодня и вчера (`BACKFILL_DAYS`); в полночь кнопки снимаются.
- **Доводчик:** один раз через 40 мин ответом на блок — неотмеченное + своя фраза (только вечерние блоки, `EVENING_FROM=21:00`).
- **Закрытие:** вечерний блок отмечен целиком в свой день → фраза из пула `closing` (без повторов неделю), ~27% — своя.
- **Утро** (`morning_digest_time`, 08:00): «Вчера» — что отмечено, неотмеченное кнопками (`y:<habitId>:<date>`).
- **Команды:** `/today /skip /фраза /фразы /удали /мысль` (+ `phrase phrases unphrase note`). Мысли (`notes`) бот никогда не показывает.
- Отключены: утренний план, вечерний итог, «серия под угрозой», «возвращайся». Недельный отчёт — остался.
- Всё «отправлено/пропущено» — в `notification_log` (type `reminder|nudge|closing|skip|yesterday`, slot `block_HH:MM`):
  проверки идут каждую минуту по журналу, поэтому переживают перезапуск.
- Тексты нейтральные: без стриков, процентов, «не забудь» в сообщениях бота (в приложении стрики остаются).

## Google Таблица — только для просмотра

Таблица finance-bot (`SHEET_ID`, ключ `/opt/arc-notifications/secrets/google.json`). Листы **«Привычки», «Отметки», «Мысли»**
перезаписываются целиком из PocketBase: после нажатия в боте, `/мысль` и раз в 5 минут (если что-то поменялось).
Правки руками затрутся. Лист «Рутина» — архив routine-bot, не обновляется. Остальные листы — контракт finance-bot, не трогать.

## Данные

- `habit_logs`: одна запись на привычку и дату, снятие = удаление (как в приложении). `created` — время отметки
  (с миграции 1792820000; у старых записей пусто, кроме перенесённых из routine-bot).
- Бэкапы перед миграциями/переключением: `/root/backups/arc-data-*.db`.

## Деплой и проверка

Push в `main` → Actions: сборка, `npm test` сервиса → rsync фронта, хуков, миграций и сервиса (кроме `.env`, `secrets/`,
`node_modules`) → `npm ci` + рестарт. Секреты и `.env` только на сервере.

```bash
cd notification-service && npm install && npm test && npx tsc --noEmit -p .
ssh maxbot 'journalctl -u arc-notifications -n 50 --no-pager'
```
Разовый код против живой базы — файлом `.ts` в `/opt/arc-notifications` (там `"type": "module"`), запуск через
`node_modules/.bin/tsx` с `set -a; . ./.env`.
